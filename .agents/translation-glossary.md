# Translation Glossary (English to French)

Working reference for the French translation. This file lives outside `skills/` and is not part of the translated surface.

## Decisions

- Scope: markdown under `skills/` only. Everything outside `skills/` stays English.
- Register: **vous**.
- Typography: non-breaking space before `:` `;` `?` `!`, guillemets `« »`, no em-dashes.
- Headings are translated; internal anchors are updated to match.
- Artifacts: French prose (issues, specs, docs, PR bodies). Code, identifiers, file names, and commit messages stay English.
- Frontmatter: `description` is translated. `name`, `argument-hint`, and `disable-model-invocation` stay English.
- `agents/openai.yaml`, scripts, and config stay English.
- Command names, paths, URLs, code spans, and code blocks are copied verbatim.
