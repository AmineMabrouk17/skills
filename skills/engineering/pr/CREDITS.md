# Crédits

Le menu de visuels de la section **Summary** (pseudocode, call trees, component trees, file trees, Mermaid, diffs) et ses conseils de placement viennent du skill [`show-me`](https://github.com/humanlayer/humanlayer) de [Dex Horthy](https://github.com/dexhorthy), reproduit presque mot pour mot et orienté vers un diff plutôt que vers une conversation en direct. `pr` ne dépend pas de `show-me` comme skill (il ne fait pas partie de ce repo, et une dépendance dure casserait les installations autonomes), donc le contenu est recopié plutôt que pointé ; ce fichier est l'attribution qu'une dépendance aurait autrement portée.
